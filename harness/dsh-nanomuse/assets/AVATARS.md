# 桌面头像资源

默认头像采用 Hatch 素材。头像静态图和状态动画通过 `/nanomuse/assets/<文件名>` 提供：

| 状态 | 文件 |
| --- | --- |
| 静态图 | `hatch.jpg` |
| 待机 | `hatch.mp4` |
| 工作 | `hatch_working-7x12.mp4` |
| 等待 | `hatch_waking.mp4` |
| 完成 | `hatch_milestone_level_up.mp4` |
| 制作动作，可复用 | `hatch_making_something.mp4` |

绘制头像和表情头像仍由账号设置决定。旧的 `dragon-*` 文件保留在资源目录，但默认头像组件不再加载它们。
